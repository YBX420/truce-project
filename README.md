# TRUCE project page

Static research project page. GitHub Pages publishes the main branch root at https://ybx420.github.io/truce-project/ . No build step is required.

The current page contains the system overview, original figures, the 100-task dynamics comparison (300 runs) and the four-planner comparison (240 runs). Experimental values follow the current submission manuscript. The two protocols are reported separately.
